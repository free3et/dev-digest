## 1. Decisions

- **F1 Move = mechanical.** T83 moves with plain `mv` (files are untracked) the set from `…/EvalsTab/`: `EvalRunControl/`, `EvalRunHistory/`, `RegressionBanner/`, `EvalCompare/` (+subfolders), `helpers.ts`, `helpers.test.ts` → `client/src/components/agent-evals/` (`AE/`). Edit import specifiers only; no assertion/text/logic edits. No new `AE/index.ts` barrel (consumers import each folder's own `index.ts`). `METRIC_COLOR` + `MetricField` move verbatim from `…/EvalDashboard/constants.ts` to `client/src/components/eval-metric/constants.ts` (`EM/`), re-exported from `EM/index.ts`; the emptied `EvalDashboard/constants.ts` is deleted. `EvalCasesList/`, `EvalsTab.tsx`, `EvalsTab.test.tsx`, `styles.ts`, `index.ts` stay.
- **F2 Series helpers** in `AE/helpers.ts` (next to `isFinished`), added after the move: `finishedOldestFirst(runs)` (filter `isFinished`, reverse); `metricPoints(runs, field): number[]` (finished, oldest first, non-null only).
- **F3 Sparkline is app-side** `EM/MetricSparkline/`: plain SVG, stroke ≥ 2 px (vendored is 1.5, no name), `<span role="img" aria-label>` around `<svg aria-hidden="true" focusable="false">`, no tabindex; props `{points:number[], color, metricLabel, width?, height?}`; < 2 points → `null`; flat series at mid-height; name from `metricFormat.sparklineName` with `from`/`to` = `toPercent(first/last)`.
- **F4 One dashboard request at limit 50.** New `EvalDashboard/constants.ts`: `RECENT_FETCH_LIMIT = 50`, `RECENT_SHOWN = 10`. `EvalDashboard` and `RecentRuns` both call `useEvalRecentRuns(RECENT_FETCH_LIMIT)` (same key → one request); `RecentRuns` renders `data.slice(0, RECENT_SHOWN)`; `EvalDashboard/helpers.ts` `recallPointsByAgent(items): Map<agent_id, number[]>` (per-agent group newest-first → `metricPoints(group,"recall")`); `AgentCard` gets `recallPoints?: number[]` (`undefined` while loading/error). Hook default `limit=10` unchanged (`lib/hooks/eval.test.tsx:229-234` pins it).
- **F5 AC-27 layout:** no slot reserved without a sparkline; metric blocks and chevron stay right-anchored (`flexShrink: 0`); sparkline takes width from the left column (`minWidth: 0`, name ellipsized). Manual check T97.
- **F6 UUID gate:** local `isUuid` in `AgentEvalPage/helpers.ts`, lenient 8-4-4-4-12 hex case-insensitive, nil accepted (same as Zod 3 `.uuid()`); non-UUID → every hook gets `null`, nothing sent.
- **F7 Page state:** pure `pageState({validId, agent, runs})` → `invalid | loading | notFound | error | ready` (notFound when invalid id or agent/runs `ApiError.status===404`; error when agent errored non-404/network; ready when agent has data). Colocated hook `AgentEvalPage/hooks/useAgentEvalPage.ts` calls `useAgent(validId)`, `useAgentEvalRuns(validId)`, `useAgentEvalCases(validId)` and returns `{state, agent, runs, cases, retryAgent}`; `page.tsx` calls it once (crumb label "Agent" unless ready).
- **F8:** while `runs` loading show one loading text (no "No finished runs yet." flash); on non-404 runs error render cards/trend from `[]` and hide subtitle; AC-22 no-cases block only when `cases.data` loaded with length 0.
- **F9 Switcher:** native `<select>` in `AgentHeader/AgentSwitcher/` with `VISUALLY_HIDDEN` `<label htmlFor>` "Switch agent" and `aria-describedby` hidden description; options from `switcherOptions(rows, current)` (case-insensitive name sort, `agent_id` tiebreak, current added when absent); not rendered while `useEvalDashboard` loading/errored; `onChange` → `useRouter().push('/eval/${id}')` only when id differs.
- **F10 Trend chart** `MetricTrend/` imports `recharts` directly (never via `@devdigest/ui`): `ResponsiveContainer` (h 240) → `LineChart accessibilityLayer={false}`; `XAxis dataKey="idx"` with `tickFormatter` → `label`; `YAxis domain={[0,100]} ticks={[0,25,50,75,100]}` with `%`; one `<Line>` per series with data (`METRIC_COLOR`, strokeWidth 2, `connectNulls={false}`, `isAnimationActive={false}`, dot r 2); series null everywhere → no `<Line>`; `Tooltip content={<TrendTooltip/>}`; legend = text list in card header ("Recall"/"Precision"/"Citation" or "<Metric> (no data)", swatches aria-hidden), not Recharts `Legend`; text alternative `<div role="img" aria-label={summary}>` wraps `<div aria-hidden="true">{chart}</div>`; `VISUALLY_HIDDEN` `<table>` with `<caption>` is a SIBLING of the role="img" wrapper.
- **F11 Trend helpers** `MetricTrend/helpers.ts`: `trendRows(runs)` → `{idx,id,version,label:"v<version>",ran_at,recall,precision,citation}[]` oldest first, `toPercent`, null stays `null`; `seriesHasData(rows,key)`; `tooltipContent(row)`. `TrendTooltip({active,payload})` renders from it (`agentPage.trend.tooltipHeader` rich with `<RanAt>`, `tooltipMetric`).
- **F12 i18n:** additive keys in `client/messages/en/eval.json` (T84). Staged `dashboard.metricTrend`/`dashboard.legend.*` untouched. `dashboard.openEvalsFor` removed in T96 only after `rg` shows zero call sites.

**Open spec issues (no change made):** (a) NFR-5 "`/eval` does not load Recharts" may already be false because the `@devdigest/ui` barrel re-exports Recharts (`client/src/vendor/ui/index.ts:7`) — T97 measures; do not edit vendor; the ≤ 5 kB growth clause still applies. (b) EC-9 assumes window-focus refetch, which production disables (`providers.tsx:28`). (c) Not-found shows after one retry (~1 s) in production (`retry: 1`); tests use `retry:false`.

## 2. Architecture constraints

`page.tsx` thin; single-route parts in `client/src/app/eval/[agentId]/_components/AgentEvalPage/…`, children used by one parent nested (`AgentHeader/AgentSwitcher/`); two-route parts in `AE/` or `EM/`; `/eval`, `/eval/[agentId]`, `/agents/[id]` never import each other's `_components`; `lib/` never imports `components/`/`app/`; no new feature barrel; tests are siblings; components render, pure rules in `helpers.ts`, state derivation in the colocated hook; no `fetch` in components; no new `lib/hooks` hook/key/polling (NFR-2); strings only via `eval.json` (camelCase, plurals with `t(key,{count})`, uppercase by styling); `import type` from `@devdigest/shared`; `client/src/vendor/**` untouched; times only client-side. Security (NFR-3): URL segment reaches an API path only after `isUuid`; no `dangerouslySetInnerHTML`; names/provider/model only as React text, `title`, `aria-label`, option text.

None. No vendor sync, no server/DB, no migration.
